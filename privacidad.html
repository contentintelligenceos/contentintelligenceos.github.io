Política de privacidad de FARO

Vigente desde el 21 de noviembre de 2026.

Quién la usa

FARO es una aplicación de uso personal. Solo la usa su propietario para gestionar sus propios canales de YouTube. No tiene usuarios externos.

Qué datos de Google usa

  • Permiso para subir videos y miniaturas a los canales del propietario.
  • Estadísticas de esos canales (vistas, retención, impresiones y clics de miniaturas) mediante YouTube Analytics y YouTube Reporting.
  • Búsquedas de videos públicos de YouTube para estimar la demanda de un tema.

Cómo se guardan

Los permisos de acceso se guardan cifrados en el equipo del propietario y no salen de él. Las estadísticas se guardan en ese mismo equipo para mejorar los siguientes videos. FARO no vende, comparte ni transfiere datos a terceros, ni los usa para publicidad.

Cómo revocar el acceso

El acceso puede retirarse en cualquier momento desde myaccount.google.com/permissions. Al hacerlo, FARO deja de poder subir videos o leer estadísticas.

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. FARO usa los servicios de API de YouTube y acepta las Condiciones del Servicio de YouTube; consulta también la Política de privacidad de Google.
